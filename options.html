Webtoon Translator

  1. Get a free Gemini key at Google AI Studio and paste it below.
  2. Press Save, then Test my key.
  3. Open a chapter on Kakao and press the blue EN button (or Alt+T).
The key stays on this computer, in the extension's own private storage. It is sent only to Google (generativelanguage.googleapis.com) with each translation request. The developer never receives it.
Any Gemini model that accepts images. Flash class models are the best mix of speed and cost. Panels you scroll past in this window are stitched into one image and sent as a single request.

Local models (Ollama)

Run a model on this computer instead of, or alongside, Gemini. Install Ollama from ollama.com and download a model first. When a local model is used, that work never leaves your computer. Finding bubbles in tall webtoon panels is hard for small local models. Gemini is much more reliable at it. With a model on this computer, it rewrites each line from the Korean text and the reader only finds the bubbles. Chrome's built-in translator needs Chrome 138 or newer and downloads a small language pack the first time. It translates Korean to English only. Only this computer is allowed (localhost or 127.0.0.1).
Models that work well for translation include translategemma and Hunyuan-MT (names containing "hunyuan" or "hy-mt" get that model's own prompt style automatically).

Quality test

Runs 50 typical webtoon lines through the local translation model above and scores the wording against a human translation (0 to 100), so you can compare models on your own computer. Run it once per model.

Back up your settings

Exports your model, language, wait time, series notes and saved fixes to a file. It never includes your API key or the translation cache.
On a Kakao chapter, use the gear button above the EN button for series notes, saved corrections and the images sent to Gemini. Click any translated bubble to edit it.
